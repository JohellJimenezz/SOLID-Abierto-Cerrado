# SOLID-Abierto-Cerrado
Tarea abierto cerrado

consiste en que las clases sean abiertas en extensiones pero cerradas en modificaciones, es decir que si el dia de mañana quiero agregar una clase nueva con funcioens que herede todo lo de la clase padre lo puedo hacer
pero no puedo modificar lo de las clases ya creadas

por ejemplo nombre y precio en la clase padre luego ya no se puede modificar
